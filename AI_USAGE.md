# AI Usage Note

I used AI assistance primarily for the frontend part of this project — helping with the HTML templates, CSS styling, and minor UI layout suggestions. I also used it occasionally for quick suggestions on library choices and boilerplate.

The backend architecture, business logic, state machine design, inventory model, and fulfillment workflow were designed and implemented by me. All trade-off decisions — such as choosing a modular monolith over microservices, server-rendered Jinja over React, and a deterministic seed fixture over a random data generator — were made based on my own judgment of what the problem required.

AI was not the decision-maker here; it was a tool I used selectively for speed on the frontend and minor lookups.
